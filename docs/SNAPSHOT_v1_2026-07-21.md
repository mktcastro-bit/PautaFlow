4. `004_add_brand_logo.sql` — upload de logo no wizard
5. `005_add_brand_website.sql` — website da marca
6. `006_add_logo_variations.sql` — múltiplas variações de logo

### Tabelas principais
- `auth.users` (Supabase Auth)
- `public.organizations` — tenant top-level
- `public.organization_members` — vínculo user↔org (owner/admin/member)
- `public.workspaces` — subespaços dentro da org
- `public.brand_dna` — DNA de 5 etapas
- `public.pautas` — pautas com `slides`, `editor_state`, `caption` em JSON
- `public.generated_content` — histórico de gerações
- `public.calendar_events` — calendário editorial

### Trigger importante
`on_auth_user_created` → cria automaticamente organização + workspace ao registrar usuário.

## ✨ Features implementadas (estado atual)

### Autenticação e onboarding
- Login/registro/callback via Supabase Auth
- Trigger automático: novo usuário → nova organização + workspace
- Reset de senha via painel Supabase (fluxo "esqueci senha" não implementado ainda no app)

### Brand DNA (wizard 5 etapas)
- Etapa 1: dados básicos (nome, website, ofertas, logo)
- Etapa 2: público-alvo
- Etapa 3: tom de voz
- Etapa 4: concorrentes e diferenciais
- Etapa 5: pilares de conteúdo
- Extração automática de conteúdo do site pra ancorar as gerações
- Upload de logo com variações (fundo claro/escuro)
- FontPicker com autocomplete e fontes do sistema

### Geração de conteúdo (Claude)
- Geração de ideias baseadas no DNA
- Modos: hint / suggestion / news (news = "apresentador", não "opinador")
- Geração de textos (título + subtítulo + callout) com JSON estruturado
- Retry com backoff em 429/overloaded
- Tracking de tokens_used em todas as gerações

### Editor de artes (art-editor)
- 3 abas: **Fundo** / **Texto** / **Elementos**
- **Fundo:** cor sólida / gradiente / imagem upload + overlay opcional
- **Texto:** posição vertical, alinhamento, tamanho (sm/md/lg), cor, cor de ênfase
- **Elementos:** barra de acento, handle da marca, número do slide, **categoria no topo** (nova — `28e8349`), logotipo, formas/ícones/imagens livres
- Customização visual por slide (toggle "Todos os slides" vs "Slide N")
- Handles de resize/rotate com camadas
- Layouts automáticos por posição (bigNumber, quoteMarks, insightTag, ctaArrow, etc)
- Presets tipográficos vindos do brand-style
- Overrides por slide: layout custom, elementos escondidos, editorState parcial

### Pautas
- CRUD completo
- Status: ideia / em_desenvolvimento / aprovado / publicado / arquivado
- Seletor rápido de status no card
- Tags, prioridade, data agendada
- Salva `slides` + `editor_state` + `caption` em JSON

### Calendário editorial
- Eventos vinculados a pautas
- Agendamento por data/hora
- Multi-plataforma (Instagram, LinkedIn, etc)

### Pagamentos
- Stripe integrado (checkout + webhooks)
- Tracking de uso de tokens por organização

### Admin
- Painel `/adminpainel` com visão geral
- Grava tokens_used em todas as gerações de IA
